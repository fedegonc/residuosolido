🎨 Design System

Tokens, componentes y reglas reales del frontend — leídos directamente de app.css y fragments/, no una descripción aparte que se desactualiza

📐 Reglas del Frontend

Sin framework CSS

CSS puro con variables + BEM. Sin Tailwind/Bootstrap — app.css, 350 líneas, 27 secciones

Sin framework JS

Vanilla JS. app.js es solo lo global/reusado por 2+ páginas; lo exclusivo de una página va en su propio archivo

i18n vía data-attr

Atributo data-i18n con la clave del copy; app.js lo reemplaza en runtime desde /js/i18n.js

Fragments como raíz única

Todo campo de formulario nace en fragments/forms.html — nunca se repite un <input> a mano en 2 templates

🔤 Tipografía

Fuente: Plus Jakarta Sans (self-hosted, font-display:fallback — ver VISUAL_PERFORMANCE_PATTERNS.md). Escala ratio 1.125 desde 16px, --text-3xl rompe el ratio a propósito (única "display").

--text-2xs (10px) — metadata mínima

--text-xs (12px) — hints, labels de stat-card

--text-sm (13px) — card__subtitle, badges

--text-base (14px) — cuerpo de texto, botones

--text-md (16px) — base del documento

--text-lg (18px) — labels de formulario destacados

--text-xl (20px) — card__title

--text-2xl (23px) — títulos de sección

--text-3xl (32px) — hero, único "display"
