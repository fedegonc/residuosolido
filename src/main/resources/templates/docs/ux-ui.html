🧭 UX/UI & Calidad

Decisiones de experiencia + cómo se verifica que el sistema funciona: tests unitarios, carga y usabilidad

🎯 Principios de UX aplicados

Mobile-first

Breakpoints: 640px (grids), 768px (navbar__lang), 1024px (navbar mobile) — el layout base es de una columna

Feedback inmediato

Flash messages tipados (success/error/warning/info) sobreviven un redirect — el usuario nunca se queda sin saber qué pasó

Accesibilidad básica

Skip-link, :focus-visible visible, 12 aria-label + 7 aria-hidden en los fragments compartidos (heredado por todas las páginas que los usan)

PWA instalable

Manifest + Service Worker — funciona como app en el celular sin tienda de aplicaciones

Sin Layout Shift

Fuente con font-display:fallback + preload, i18n aplicado post-paint — ver patrones de performance

Guest-first

Solicitar y rastrear una recolección no exige crear cuenta — la fricción de registro queda para quien de verdad la necesita

✅ Cómo se verifica que funciona

Tests Unitarios & Integración

Suite completa vía mvn test -DexcludedGroups=browser — el conteo cambia con cada mejora, ver histórico en MEJORAS.md

Smoke Test de Carga

20 usuarios concurrentes × 15 requests contra endpoints reales (home, formulario, health) — sin herramienta externa, corre con mvn test. Ver mejora #202

Instrumento de Usabilidad

Encuesta Likert por funcionalidad, preparada para aplicar con usuarios reales — estado: preparado, aún no aplicado

Auditoría de Bugs Visuales

3 bugs específicos encontrados por barrido sistemático (imágenes sin dimensiones, modal sin scrollbar-gutter, fetch sin loading state)

⚠️ Lo que falta (depende de datos reales)

Pendiente, no se puede simular

La usabilidad real y las métricas de uso en producción (Render) requieren usuarios reales interactuando con el sistema — con 0 usuarios activos hoy, esto queda como trabajo futuro declarado, no como un gap oculto. El instrumento Likert ya está preparado para aplicarse apenas haya usuarios; las métricas de Render (latencia real, errores en producción) se miden pasivamente vía /actuator/health una vez que haya tráfico que observar.
